FLOCON pour Windows — il neige sur votre bureau
Version 1.0 — Windows 10 et 11

INSTALLER
1. Dézippez le dossier où vous voulez (par exemple dans Documents).
2. Double-cliquez sur Flocon.exe.
3. La première fois, Windows affiche « Windows a protégé votre ordinateur ».
   Cliquez sur « Informations complémentaires », puis sur « Exécuter quand même ».
   C'est normal : Flocon est une petite app indépendante, sans certificat payant.

SI WINDOWS BLOQUE FLOCON SANS PROPOSER « EXÉCUTER QUAND MÊME »
Le message commence par « Le Contrôle intelligent des applications a bloqué… ».
C'est une protection de Windows 11 qui refuse toutes les apps sans certificat payant.
Pour utiliser Flocon, il faut la désactiver :
1. Ouvrez « Sécurité Windows », puis « Contrôle des applications et du navigateur ».
2. Cliquez sur « Paramètres du Contrôle intelligent des applications ».
3. Choisissez « Désactivé ».
Attention : Windows ne permet pas de la réactiver ensuite sans réinitialiser le PC.
Votre PC reste protégé par l'antivirus de Windows.

UTILISER
Flocon n'a pas de fenêtre : il vit dans une icône près de l'horloge, en bas à droite.
Si vous ne la voyez pas, cliquez sur la petite flèche ^ à côté de l'horloge
(vous pouvez ensuite faire glisser l'icône à côté de l'horloge pour la garder visible).
Cliquez sur l'icône pour :
- activer ou désactiver la neige ;
- régler la cadence de la neige ;
- envoyer le chasse-neige, qui dégage le bas de l'écran ;
- ouvrir Flocon au démarrage de Windows ;
- quitter Flocon.

JOUER AVEC LA NEIGE
- Passez le curseur dans la neige : il la balaie.
- Secouez une fenêtre : sa neige tombe. Rétrécissez-la : ce qui dépasse bascule dans le vide.
- Cliquez dans la neige et gardez le bouton enfoncé : une boule naît. Faites-la rouler
  dans la neige pour la grossir, puis lâchez-la ou lancez-la. Trop petite, elle fond.
- Empilez trois boules : elles deviennent un bonhomme de neige.

À SAVOIR
- La neige tombe sur l'écran principal seulement.
- Flocon se met en pause quand l'écran se verrouille.
- Si vous déplacez Flocon.exe après avoir coché « Ouvrir au démarrage de Windows »,
  décochez puis recochez l'option.

METTRE À JOUR
Les nouvelles versions vous sont envoyées par e-mail. Quittez Flocon, puis remplacez
l'ancien Flocon.exe par le nouveau. Le numéro de version est affiché en bas du menu de Flocon.

DÉSINSTALLER
Décochez « Ouvrir au démarrage de Windows », quittez Flocon, supprimez le dossier.
